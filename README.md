# AWS S3 Static Website Hosting Project

## 📌 Project Overview

This project demonstrates how to host a static website using Amazon S3.

The website is created using HTML and CSS and hosted on an Amazon S3 bucket.

## 🛠️ Technologies & AWS Services Used

- HTML
- CSS
- Amazon S3
- S3 Static Website Hosting
- S3 Bucket Policy
- GitHub

## ⚙️ Project Steps

### 1. Create S3 Bucket

Created an Amazon S3 bucket named:

`megha-s3-static-website`

Region:

`Asia Pacific (Mumbai) - ap-south-1`

### 2. Create Website Files

Created two website files:

- `index.html`
- `style.css`

### 3. Upload Files to S3

Uploaded `index.html` and `style.css` to the S3 bucket.

### 4. Enable Static Website Hosting

Enabled Static Website Hosting in the S3 bucket.

The index document was configured as:

`index.html`

### 5. Configure Bucket Policy

Added an S3 bucket policy to allow public read access to website objects.

### 6. Test the Website

Opened the S3 website endpoint in a web browser and verified that the website was working successfully.

## 🌐 Live Website

The website was successfully hosted and tested using Amazon S3.
